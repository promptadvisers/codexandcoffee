# Day 9: Make an Explainer People Can Follow

A 45-minute lesson on creating instructional videos with Codex and HyperFrames.

## Presentation

- [Download the PowerPoint](https://github.com/promptadvisers/codexandcoffee/raw/refs/heads/main/day-09/Day-09.pptx) — 52 slides, five chapters, full videos and focused replays embedded

Each chapter follows: divider → full video → actual production brief → design choices → scene-by-scene breakdown → focused replay. The deck includes speaker notes and learner practice.
