# Quote & Proposal Studio

A fictional consulting quote application for Codex & Coffee, Day 3. Build a quote, explore discounts, check delivery margin, save proposals locally, and export a client-facing HTML proposal.

Run with Node.js 20 or newer: `npm start`, then open http://127.0.0.1:4323. No npm install or account is needed. Saved proposals remain only in your current browser and origin. Export to keep a portable proposal. This demo does not collect payments, send proposals, or connect to other systems.

The starting version is intentionally written in one module as a prepared teaching example. Its structure is the subject of the lesson; it is not a production architecture recommendation. Refactoring must preserve the documented, tested behavior. Existing behavior is not automatically ideal behavior.
