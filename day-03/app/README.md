# Finished Quote Studio

A self-contained fictional consulting quote app for Day 3. This copy has the completed pricing extraction.

Use Node.js 20+: run `npm start`, open http://127.0.0.1:4323, and run `npm test` to see 27 checks. No npm install is needed. Use the Day 3 START-HERE.md for the before/after workflow.

Saved quotes stay in the current browser and origin. The demo does not send proposals, collect payments, call an AI model, or connect to other systems.
