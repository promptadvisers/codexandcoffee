Fifteen diagram sections walk through how Codex takes a request, brings in project rules, asks the AI for a next step, runs tools, checks permissions, and keeps track of the conversation. Two worked examples show checking an order update and fixing an incorrect price.

## Use the reference

Choose a topic from the side menu or dropdown. Use the left and right arrow keys to move between sections. Blue code links open the relevant files in the public Codex GitHub repository.

The offline HTML includes its diagrams and fonts. Save it and open it in a browser; no installation is needed. Internet access is needed only for the GitHub source links.

## Edit the board

Open [Excalidraw](https://excalidraw.com), choose the top-left menu → **Open**, and select `Inside-the-Codex-Harness.excalidraw`. Zoom into one numbered frame at a time. The titles, labels, shapes, arrows, and code links are editable.

The board uses the public `openai/codex` snapshot `4b4a5cf25aa5b064c866218b405c848745fd280f`. The two examples are prepared, checked teaching examples, not recordings of a Codex run. This is a teaching map of the public harness, not every internal component.

This download contains the board and visual reference. The Day 6 PowerPoint and example starter folders are not included.
