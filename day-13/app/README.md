# StageInk source

Independent presentation drawing tools created for Codex & Coffee Day 13.

- [Mac source and build script](macos/)
- [Windows source and instructions](windows/)

The Mac edition requires macOS 13 or later. The Windows edition targets Windows 10 and 11 x64. Both offer the same core pen, shapes, boards, undo, clear and timer workflow. Platform-specific shortcuts are documented in each folder.

Release 0.2 moves Mac settings into Application Support so installation in Applications works. The Windows version is a separate WPF implementation. The lesson's recorded first-build evidence remains unchanged.
