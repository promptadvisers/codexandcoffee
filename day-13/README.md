# Day 13 · Rebuild an app with Codex

A 45-minute lesson on inspecting DemoPro, using Computer Use and REA, writing a specification, planning an independent app and checking the result.

- [Download the PowerPoint](https://github.com/promptadvisers/codexandcoffee/raw/refs/heads/main/day-13/Day-13.pptx)
- [Read the app source](app/)

StageInk includes pen, line, arrow, rectangle and ellipse tools, color and width choices, undo and clear, presentation boards, a break timer and a practice surface. The Mac edition uses Swift and AppKit. The Windows edition uses C# and WPF.

The lesson includes the original Mac experiment. The downloadable editions receive additional packaging and platform work. Their build and test records are provided with the release. Physical drawing and full-screen behavior need a check on your own computer.
