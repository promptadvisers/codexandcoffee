# 180 practical Codex use cases
These are opportunities to adapt, not claims that 180 integrations have been deployed. A working connection, useful source data and a test are needed for each real workflow. Model choices are starting points; arithmetic and explicit business rules belong in ordinary code.

- **Discovery preparation:** Questions from account context
- **Call-note summaries:** Needs, objections and next steps
- **Competitor comparisons:** A source-linked comparison
