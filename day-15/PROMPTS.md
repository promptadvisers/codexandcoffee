# Adaptable Codex prompts

Replace bracketed text with your real context. The department discovery and build prompts are two messages in the same chat. They are templates, not tested integrations with your systems.

## Slide 13 — Sales · Find the best opportunity

START IN THE DEPARTMENT PROJECT · ADAPT THE BRACKETS

```text
Help me find the best ways to use Codex for sales. Here is our context: [goals, people we serve and how we work]. Our biggest bottleneck is [what takes too long or keeps going wrong].

Our systems are [tool names], and their documentation or API links are [URLs]. Read the relevant docs and inspect the materials I provide. Ask about any missing context that would change your recommendation.

Suggest five useful workflows. For each, show the inputs, result, required access, and whether it should run on demand, on a schedule, or as a connected workflow. Rank them by likely value and setup effort.
```

## Slide 14 — Sales · Build the chosen workflow

FOLLOW UP IN THE SAME CHAT · ADAPT THE BRACKETS

```text
Let’s build [the workflow we chose]. The useful result is [what I want back], and success means [a specific check].

Use the context and system documentation we just reviewed. Show me the simplest plan and explain which parts need a model, ordinary code or my judgment. Use my existing Codex setup where it fits; identify any separate API, account or hosting requirement.

Build and test it on a small sample first. Keep existing records intact and show me the result and any exceptions. Once it works, help me make it reusable and choose how it should run.
```

```text

```
