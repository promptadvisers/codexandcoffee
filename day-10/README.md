# Day 10: Make Images That Belong Together

A 60-minute image-generation workshop with 56 slides, annotated prompts, a fictional product campaign and hands-on practice.

## In this lesson

- Keep a shared visual brief across a deck and change only the subject needed for each image
- Understand image–text training, learned weights, diffusion and visual tokens through plain-language examples
- Use reference images and explicit constraints to reduce changes to a recurring product
- Compare real results, spot missing details and request a focused repair
- Reuse an approved image file when the artwork must remain identical

Slides 6–7 put consistency guidance near the opening. The kit includes the style reference, two complete style-matching prompt templates, the ASTER bottle master, actual generated results, a worksheet and an answer key.

## Sources and example boundaries

Current model and prompting guidance comes from [OpenAI’s GPT Image 2.6 prompting guide](https://developers.openai.com/api/docs/guides/image-prompting) and [image-generation documentation](https://developers.openai.com/api/docs/guides/image-generation). Published historical training methods are distinguished from the undisclosed details of the latest model.

The custom ASTER images are actual Codex image-tool outputs; that tool did not expose its backend model ID. The kit clearly distinguishes completed examples from reusable templates. No prompt guarantees identical regenerated artwork. The slides demonstrate exact source-image reuse separately.
