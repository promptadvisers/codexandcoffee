# Day 12: Your Personal Assistant, in Codex and Beyond

A 55-minute lesson with 35 slides: use native Codex features as a personal assistant, then see how a custom app can use the Codex SDK.

## What we cover

- Projects, focused chats, instructions and plugins
- Scheduled jobs and checking their results
- Using Codex from a phone and understanding where work runs
- What an SDK does, in plain English
- The difference between the Codex SDK, app server and API-key billing
- Gratis as a concrete example of a custom assistant app
- A real SDK response and a follow-up in the same conversation
- An exact prompt for building a first local assistant

The latest deck includes the recreated wide bot-identity illustration on slide 24. It is identified in the notes as an illustration, not a live application screenshot.

## Try the learner kit

Extract the ZIP and start with its README. It includes three copyable prompts and a small local SDK app. The app needs Node.js, an installed Codex client and your own eligible sign-in. It keeps a conversation while the local server runs; persistent storage, scheduling and remote access are separate additions.

The SDK example was run successfully with fictional text, then continued in the same conversation. Native schedules, phone pairing and connected accounts are documented setup flows; they were not activated for this lesson. Gratis's Codex integration was verified in its installed code; the illustrated interface is not evidence that every displayed conversation used Codex.
