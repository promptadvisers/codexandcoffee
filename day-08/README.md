# Day 8: Editing Videos with Codex

A self-contained, 45-minute lesson with 35 slides. Start with a rough recording, ask for a cut plan in plain language, and turn the accepted plan into a checked video.

- [Download the offline presentation](https://github.com/promptadvisers/codexandcoffee/raw/refs/heads/main/docs/day-08/index.html)

## What the lesson covers

- Codex, FFmpeg, HyperFrames and optional Auphonic audio cleanup
- Why a small cut can span many video frames
- Asking for edits in ordinary language and reviewing the proposed cuts
- Keeping complete words, correct prices and useful pauses
- Audio, captions, screen framing and checks before sharing an export

GPT-6.1 Terra is the main model example. The slides distinguish the model’s planning work from local video processing. The examples are fictional and use synthetic narration.

## Use the materials

Open the PowerPoint to edit or present the slides. Its notes contain the teaching guide and exact prompts. The browser presentation includes the original recording, edited result and a short HyperFrames animation; use the topic menu or arrow keys to navigate.

Unzip the learner kit and start with `video-editing-kit/README.md`. Open that folder in Codex. The kit includes the recording, transcript, prompts, prepared results, an editable graphic and a local rendering helper. Its project instructions handle file names and the cut-list format so requests can stay conversational.

The supplied edit is about 25.33 seconds, shortened from 36.63 seconds. The exact cut-plan and render requests were rehearsed, and a clean-folder render reproduced the result. Auphonic is an optional explained step; no cloud-audio job is required. Listen to the result yourself before treating an edit as finished.
