A 45-minute lesson with 48 slides, five workflow structures, plain-English prompts, and tested examples.

Save the HTML file and open it in a browser. It includes topic navigation and speaker notes. The PowerPoint includes editable diagrams and prompt text.

## What we cover

- One agent following ordered steps
- Choosing a saved skill for a familiar job
- Two independent reviewers
- A coordinator who waits for reviews before assigning a writer
- Checking the result and handling missing information

Each practice exercise includes a simple approach and a team approach, with a diagram and a complete prompt for each.

## Use the learner kit

Extract the ZIP, read its README, and open the workshop-launch folder in Codex. The kit includes approved fictional event facts, a writing guide, an original draft, a review skill, prepared checks, ten exact prompts, and recorded results.

All ten prompts were run against isolated copies of the exercise. The examples show observed behavior, not a guarantee of identical wording or a performance advantage from using more agents. The fixed event date and details are fictional. Nothing in the exercise sends or publishes content.

The prompts use plain language; technical setup details stay inside the kit. The prepared check script requires Python 3 on the host. You can also read the examples and write prompts without running it.
